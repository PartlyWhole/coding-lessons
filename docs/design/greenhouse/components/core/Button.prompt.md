Pressable Trellis button — primary (Bluebell, hard under-shadow, depresses 2px on :active) for the step's main action; ghost (outline, accent-ink) for hint/peek-back asides.

```jsx
<Button>Run & check</Button>
<Button variant="ghost">Show a hint</Button>
<Button disabled>Submit</Button>
```

Disabled primary = sunken fill + faint ink + no under-shadow (used while a choice is unmade or during EVALUATING).
