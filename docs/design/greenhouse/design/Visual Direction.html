Visual Direction v1 — “Greenhouse”

Typography · code treatment · color system incl. semantic attribution palette · spacing tokens · motion. For approval before Cell Runner layout. June 9, 2026.

Assumptions & design reasoning

Working name “Greenhouse”: a warm, light page where prose lives, and a dark terrarium panel where code lives — code reads as a distinct, special place you peer into. Soft rounded shapes and pressable buttons give the teen-friendly energy; restraint in color keeps it calm and low-anxiety.

  • The semantic palette is the loudest color on screen. Everything else (warm neutrals, one accent) stays quiet so attribution color always reads instantly — and amber never has to compete with decorative orange.
  • Misconception ≠ error is carried three ways at once: hue (warm amber vs. crimson), icon (magnifier “let’s look closer” vs. factual “!”), and label typography — never color alone (§5 a11y).
  • Determinism in tone: motion is short, mechanical and settles fast; nothing pulses or “thinks.” The only flourish is a brief check-pop on pass, as approved.
  • Fonts are Google-Fonts loaded here for preview but all three families are self-hostable (Fontsource/woff2) per the static-hosting constraint.
  • Dark mode: I propose shipping dark token values as a spec table with the final system, with full mockups light-only — keeps the deliverable tight. Flag if you want more.

1Typography

Three families, three jobs. Baloo 2 (display) brings the rounded warmth for titles and feedback labels; Nunito Sans (UI) does all reading work — humanist, generous x-height, friendly without being childish; JetBrains Mono (code) is the most beginner-legible mono we can self-host: tall x-height, unambiguous 0O / 1lI — with ligatures disabled so beginners always see the real characters they typed.

2Code treatment — the dark terrarium

One dark surface, used everywhere code appears: the CodeMirror editor, watch/predict code blocks, and revealed solutions. Deep blue-slate (never pure black) so it feels like glass, not a void. Captured stdout docks beneath the code in a darker console strip — output is visually “what came out the bottom.”

Locked regions (scaffolding the learner can’t edit): dimmed to 72%, faint fill, a dashed left rail + tiny lock beside the line number — reads as “rails of the trellis,” present but clearly not yours to change. Cursor over a locked line: default arrow, not text-beam.

Syntax colors (4 + comment, deliberately few for beginners): keyword #92B3FF · string #FFD08E · number #8BD9B9 · builtin/function #C0AFFF · comment #8290A8 italic. All ≥ 4.5:1 on --code-bg #242B39. Strings are the warmest token on purpose — strings are the hero type in week one.

The semantic attribution palette — final proposal

Each attribution gets a triad: -ink (label, icon, ≥4.5:1 on its surface), -surface (band fill), -border. Bands are soft-filled rounded panels — no harsh left-border-only treatment, no pure saturated fills. Meaning is always carried by color + icon + label together. Real authored copy below.

4Brand accent — three candidates

The accent is everything interactive but not evaluative: primary buttons, selected choices, focus rings, progress. Click a candidate to apply it to the live sample below.

Which line keeps the answer?

A · Sprout

#348F5C · deep #27714A · tint #E7F4EC. Owns the trellis/growth metaphor fully. Risk: sits close to pass-green #1A7F4B — “selected” and “correct” could blur for new learners.

B · Bluebell  ★ recommended

#5263D8 · deep #3F4FB8 · tint #ECEFFC. Periwinkle — friendly, clearly distinct from all four semantic hues, and harmonizes with the editor’s keyword blue. Green still lives in the brand glyph & future course-map foliage.

C · Grape

#8050C8 · deep #683FA8 · tint #F3EEFB. The most playful/teen of the three; also semantically clean. Slightly trickier to keep calm at large sizes.

Pressable buttons: primary actions carry a 3px hard under-shadow in the accent’s deep value and physically depress on click (translateY 2px) — tactile, game-like, zero animation cost. Focus ring everywhere: 3px --accent-tint halo + 2px accent border (visible on the warm paper).
