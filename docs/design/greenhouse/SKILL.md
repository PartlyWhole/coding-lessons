Non-negotiables for Trellis specifically: the frozen interaction semantics in
`uploads/trellis-design-handoff.md` §4; the attribution palette's meanings
(misconception = warm amber teachable moment, NEVER error-red); deterministic
register (no spinners, no "AI thinking" vibes); ligatures off in code.
