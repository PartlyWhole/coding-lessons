## 3. The headless-grading design (pinned decisions)

These four decisions make §17.4–§17.5 fit the FROZEN ladder with zero engine/schema-runtime changes. They are design-reviewable by the orchestrator alongside the schema seam.

**D1 — One synthesized entrypoint serves tests AND property.** The composed source appends `__trellis_sim(frame, *init_args)`: seed `random` (from `property.seed ?? 0`, baked at compose time), build `state = init(*init_args)` (or `None` if no `init`), apply `update(state, events, dt)` exactly `frame` times driving events off `inputTape`, return `probe(state)` (or `state` if no `probe` — must be JSON-able). So `__trellis_sim(0, ...)` probes the *initial* state. The step's effective `run.entrypoint` is rewritten to `__trellis_sim`; `tests.cases` use `input: [frame, ...initArgs]`; `property.generators` include a `frame` int generator (0..frames-1) plus init-arg generators — "compare the probe trajectory to a reference update over generated start states" becomes sampled (frame, start-state) comparison through the UNCHANGED `propertyRunner`. Cost: each call re-simulates ≤ `frames` updates; with frames ≤ 600 and modest `numCases` this stays inside the §14 budget (the fixture uses frames=120, numCases=12).

**D2 — Headless-aware locked preamble.** The single source plays AND grades because the locked preamble is authored environment-aware (this replaces §17.3's unconditional `from js import window`, which would die in the worker where the js-FFI bridge is deliberately import-blocked):

```python
import asyncio, os, pygame
__HEADLESS = os.environ.get("TRELLIS_HEADLESS") == "1"
if not __HEADLESS:
    from js import window
    os.environ["SDL_EMSCRIPTEN_KEYBOARD_ELEMENT"] = "#canvas"   # before display creation
pygame.init()
screen = pygame.display.set_mode((W, H))
GEN = 0 if __HEADLESS else int(window.gameGen)
# ... learner region: update / draw / probe ...
async def main():
    while __HEADLESS is False and int(window.gameGen) == GEN:
        update(...); draw(screen); pygame.display.flip()
        await asyncio.sleep(1 / 60)
if not __HEADLESS:
    asyncio.ensure_future(main())
```

Under dummy drivers `pygame.init()`/`set_mode` are headless-safe; the loop never starts; the appendix calls the entrypoints directly. (Flagged as ambiguity A1 — §17.6 shows the unguarded preamble.)

**D3 — `wrapGraphicalSandbox(inner)` decorator (the BuildSandbox additive-seam pattern).**
- `run(req)`: prefix `req.code` with **exactly one line** — `import os; os.environ["SDL_VIDEODRIVER"]="dummy"; os.environ["SDL_AUDIODRIVER"]="dummy"; os.environ["TRELLIS_HEADLESS"]="1"` — set `packages: ["pygame-ce"]` on the wire request, delegate to `inner.run`, and re-map `result.error.line -= 1` (prefix is 1 line; learner line numbers preserved).
- `parseAndMatch(code, queries)`: strip everything from `APPENDIX_MARKER` (`# === TRELLIS GRAPHICAL HARNESS (auto) ===`) before delegating — AST tags are computed over the LEARNER source only, never the harness (the harness references `K_*` constants and would otherwise defeat negative queries like `reads_no_input`).

**D4 — Event synthesis from the tape (deterministic).** Per frame: diff `keysDown` against the previous frame → `pygame.event.Event(pygame.KEYDOWN, key=getattr(pygame, k))` for newly-down, `KEYUP` for released; a `mouse` entry emits one `MOUSEMOTION` event with `pos`/`buttons`. The events list (possibly empty) is passed to `update(state, events, dt)`. (Flagged as ambiguity A2 — §17.4 leaves event semantics unstated.)

```ts
// §17.3 — the integer bridge between the JS step machine and the running Python loop.
// Python captures GEN = int(window.gameGen) at start; every frame it re-reads window.gameGen
// and exits its while-loop when they differ. Bumping is therefore the universal stop signal.
export interface GameGen { current(): number; bump(): number }

export function createGameGen(target: Record<string, unknown> = globalThis as never): GameGen {
  if (typeof target["gameGen"] !== "number") target["gameGen"] = 0;
  return {
    current: () => target["gameGen"] as number,
    bump: () => {
      const next = (target["gameGen"] as number) + 1;
      target["gameGen"] = next;
      return next;
    },
  };
}
```

```ts
import type { StallEvent } from "./types.js";

export interface WatchdogOpts {
  budgetMs?: number;     // default 500 — generous; play loops sleep ~16ms
  consecutive?: number;  // default 3
  raf?: (cb: FrameRequestCallback) => number;
  caf?: (id: number) => void;
}
export interface Watchdog { start(onStall: (e: StallEvent) => void): void; stop(): void }

// HONEST SCOPE (§17.5): rAF can only observe a SLUGGISH loop (long frames). A fully
// blocked main thread never runs this callback at all — preventing that is the AST
// pre-check's job (guard 1). Last-resort recovery for the learner is a page reload.
export function createWatchdog(opts: WatchdogOpts = {}): Watchdog {
  const budgetMs = opts.budgetMs ?? 500;
  const need = opts.consecutive ?? 3;
  const raf = opts.raf ?? ((cb) => requestAnimationFrame(cb));
  const caf = opts.caf ?? ((id) => cancelAnimationFrame(id));
  let id = 0; let running = false; let last: number | null = null; let streak = 0;

  return {
    start(onStall) {
      running = true; last = null; streak = 0;
      const loop = (ts: number): void => {
        if (!running) return;
        if (last !== null) {
          const gap = ts - last;
          if (gap > budgetMs) { streak += 1; if (streak >= need) { onStall({ blownBudgetMs: gap, consecutive: streak }); streak = 0; } }
          else streak = 0;
        }
        last = ts;
        id = raf(loop);
      };
      id = raf(loop);
    },
    stop() { running = false; caf(id); },
  };
}
```

```ts
import type { AstQuery } from "@trellis/schema";

export const REFUSAL_MESSAGE =
  "This loop never yields to the browser — add `await asyncio.sleep(1/60)` inside it so the page stays responsive.";

// CONSERVATIVE BY DESIGN (pinned; see plan ambiguity A3): ANY `while` with no Await
// descendant is refused pre-play. Bounded whiles are legal Python but rare in lesson
// scaffolds (authors use `for`); a false refusal is a teachable nudge, a false pass is
// a frozen tab. Attribution flavor is `syntax` (§17.5) — a deterministic rejection.
export const AWAITLESS_LOOP_QUERIES: { tag: string; query: AstQuery }[] = [
  { tag: "awaitless_loop", query: { node: "While", where: { not: { childMatches: { node: "Await" } } } } },
];

export type PrecheckResult = { ok: true } | { ok: false; refusal: string };

export async function precheckSource(
  source: string,
  parseAndMatch: (code: string, queries: { tag: string; query: AstQuery }[]) => Promise<string[]>,
): Promise<PrecheckResult> {
  const tags = await parseAndMatch(source, AWAITLESS_LOOP_QUERIES);
  return tags.includes("awaitless_loop") ? { ok: false, refusal: REFUSAL_MESSAGE } : { ok: true };
}
```

```ts
import type { RunRequest, RunResult, AstQuery } from "@trellis/schema";
import { APPENDIX_MARKER, HEADLESS_PREFIX } from "./compose.js";

interface BuildSandboxShape {  // structural twin of engine's BuildSandbox (engine stays unimported — adapter direction)
  run(req: RunRequest): Promise<RunResult>;
  parseAndMatch(code: string, queries: { tag: string; query: AstQuery }[]): Promise<string[]>;
}

export function wrapGraphicalSandbox(inner: BuildSandboxShape): BuildSandboxShape {
  return {
    async run(req) {
      const res = await inner.run({ ...req, code: HEADLESS_PREFIX + req.code, packages: ["pygame-ce"] } as RunRequest);
      if (res.error?.line !== undefined && res.error.line > 1)
        return { ...res, error: { ...res.error, line: res.error.line - 1 } };
      return res;
    },
    parseAndMatch(code, queries) {
      const cut = code.indexOf(APPENDIX_MARKER);
      return inner.parseAndMatch(cut === -1 ? code : code.slice(0, cut), queries);
    },
  };
}
```

## 5. Ambiguities & risks needing an orchestrator/user decision

- **A1 (design deviation, needs sign-off):** §17.3/§17.6 show an *unconditional* `from js import window` locked preamble; headless grading of the SAME source is impossible under the worker's js-FFI import blocker (Stream J hardening). Pinned resolution: the **headless-aware preamble** (D2, `TRELLIS_HEADLESS` guard). Alternative rejected: whitelisting a `js` shim in the worker (would re-open escalation 3's surface).
- **A2:** §17.4 leaves `events` synthesis unspecified (`keysDown` is *held-key state*, but `update(state, events, dt)` receives *events*). Pinned: edge-triggered KEYDOWN/KEYUP from per-frame diffs + MOUSEMOTION (D4). The content track must author to this contract later.
- **A3:** the AST pre-check is pinned CONSERVATIVE — any `while` lacking an `await` descendant is refused pre-play, including bounded ones inside `update`. False-refusal is teachable; false-pass freezes the tab. If the orchestrator prefers §17.5's narrower "top-level/`main` loops only", the query needs a top-level-ness selector the current `AstQuery` cannot express (a `within`-Module concept) — that would be a schema/ast-query escalation.
- **A4:** `__trellis_sim(frame, …)` re-simulates from frame 0 per call (D1) — `numCases × frames` updates per property run. Within budget for frames ≤ 600 / modest numCases; a trajectory-memoising entrypoint would need an engine seam (rejected for M6.5).
- **A5 (schema gap, deferred):** steps have no `assets` field; `boot(canvas, assets)` takes an injected `AssetSpec[]` and M6.5's fixture uses none. An authored asset manifest is a FUTURE schema seam (content track / M7).
- **A6 (environment risk):** `pygame-ce` wheel availability/behavior on Pyodide 0.27.2 from the CDN is asserted by §17 but unverified in this worktree (offline twin can't prove it). If Task 14 finds the canvas API surface differs (§17.8), use the documented `keyboardListeningElement` fallback and REPORT — no improvised architecture. Worker-side `loadPackage("pygame-ce")` memory pressure inside the 256 MB pooled cap also lands here; if the wheel blows the cap, graphical runs move to `runDedicated` with a higher `memoryMb` (config-only change, report it).
- **A7:** the offline twin tiers require local `pygame` (`pip install pygame-ce`) — tests are `skipIf`-guarded, so CI without it stays green but proves less; the defining gate is the real browser either way. Orchestrator may want pygame-ce added to the CI python deps (`.github` is NOT ours — escalate if desired).
